# Portal Cidadania Digital e Inteligência Artificial

## 🎯 Objetivo
Este site interativo serve como um portal de conscientização comunitária focado em instruir os cidadãos a identificarem desinformação automatizada e mídias alteradas por IA (deepfakes). O projeto contém uma base teórica explicativa e o jogo educacional integrado "Verdade Digital".

## 🚀 Tecnologias Aplicadas
- **HTML5 Semântico:** Uso correto de estruturas (`main`, `section`, `header`, `footer`, `form`).
- **CSS3 Moderno:** Layout responsivo baseado em Flexbox e Media Queries para adaptação mobile completa.
- **JavaScript Dinâmico:** Processamento lógico de variáveis de controle, sistema de pontuação ao vivo e inversão dinâmica de estilos (Modo Escuro).

## 🤖 Prompts Utilizados como Assistente de Produção
1. *"Gere cenários fictícios curtos em texto que exemplifiquem indícios técnicos reais de arquivos de vídeo e áudio manipulados por ferramentas de deepfake."*
2. *"Estruture funções JavaScript limpas usando manipulação clássica baseada emclassList.add e classList.remove para alternar telas invisíveis."*

## 🎨 Autoria e Alinhamento de Ética
Todo o conteúdo escrito, conceitual e criativo deste site foi produzido de forma 100% autoral por seus desenvolvedores, utilizando IA de forma estritamente ética para fins de validação e otimização de sintaxe de códigos.
